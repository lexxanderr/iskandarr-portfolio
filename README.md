# iskandarr.com — V2

Developer portfolio for Alexander Iskandar.

## Stack
- React + TypeScript
- Vite
- Lucide icons
- Plain CSS (no paid UI/template dependency)

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Deploy free
Import this repository into Vercel and use the default Vite settings. Then add `iskandarr.com` in the Vercel project's Domains settings and update the DNS records at the registrar when prompted.

## Before launch
- Replace/expand ServiceFlow when its repository is created.
- Add real screenshots to the project cards as projects mature.
- Add the final software-engineering CV to `/public` and wire a CV button to it.
- Confirm all project links and wording.
